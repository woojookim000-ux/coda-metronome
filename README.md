# 합주 메트로놈

밴드 동아리용 실시간 공유 메트로놈. 한 사람이 방을 만들고 나머지가 QR이나 코드로
들어오면, 모든 기기가 **같은 순간에** 클릭을 냅니다.

## 어떻게 맞추는가

박자 신호를 서버가 실시간으로 쏘는 방식은 쓰지 않습니다. 그러면 네트워크가
흔들릴 때마다 클릭이 같이 흔들립니다.

대신 이렇게 합니다.

1. **시계 맞추기** — 각 기기가 서버에 ping을 보내고 왕복 시간으로 자기 시계와
   서버 시계의 차이를 추정합니다(NTP와 같은 방식). 왕복이 빨랐던 샘플만 골라
   중앙값을 씁니다. 같은 와이파이에서 보통 오차 ±1~3ms.
2. **규칙만 공유** — 서버는 `"서버시각 anchor에 anchorBeat번째 박, 이후 60000/bpm ms 간격"`
   이라는 규칙만 브로드캐스트합니다.
3. **각자 예약** — 각 기기가 그 규칙으로 자기 박 시각을 계산해 Web Audio에
   미리 예약합니다. 발음 시각은 브라우저 타이머가 아니라 오디오 클럭이 정합니다.

그래서 중간에 패킷이 늦게 와도 이미 예약된 클릭은 제 시각에 울립니다.

측정값(같은 PC의 두 클라이언트 기준): 박 간격 오차 **최대 0.05ms**,
두 클라이언트 간 같은 박의 예약 시각 차이 **0.1ms 이내**.

### 이어폰 지연에 대해

블루투스 이어폰은 소리가 150~200ms 늦게 나옵니다. 다만 **절대 지연은 문제가
되지 않습니다.** 전원이 똑같이 170ms 늦게 들으면 서로는 완벽히 맞습니다.
맞춰야 할 외부 기준이 없기 때문입니다. 문제가 되는 건 **멤버 사이의 차이**뿐입니다.

| 상황 | 결과 |
| --- | --- |
| 전원 유선 | 문제 없음 |
| 전원 블루투스 (기종 달라도) | 대체로 괜찮음 |
| **유선과 블루투스 혼용** | **170ms 어긋남 — 보정 필요** |

즉 이어폰 종류를 통일하면 보정이 거의 필요 없습니다. 혼용할 때만
**내 기기 → 오디오 지연 보정**을 씁니다. 이때 다들 귀를 막고 있으면 비교할
기준이 없으므로, 호스트 폰을 스피커로 틀어 놓고 각자 한쪽 이어폰만 빼서
그 소리와 겹치도록 맞추면 됩니다.

## 기능

- 방 만들기 / 6자리 코드 · QR로 참여
- **곡 구간 표시** — 곡마다 `인트로 8마디 → A 16마디 → 후렴 8마디`처럼 등록해 두면,
  합주 중에 현재 구간 이름과 `3마디 뒤 브릿지` 카운트다운이 화면에 크게 뜹니다.
  곡 전체 진행 막대와, 마지막 구간이 끝나면 자동 정지도 있습니다.
- BPM 조절(슬라이더, ±1, 탭 템포), 박자표 2/4~7/4, 첫 박 강세
- 카운트인 1·2·4마디, 마디 카운터
- 셋리스트(곡별 BPM·박자표 저장, 순서 변경, 내 기기에 저장/불러오기)
- 기기별 설정: 소리 on/off, 볼륨, 지연 보정, 화면 깜빡임
- 호스트만 템포·시작 조절, 호스트 넘기기
- 재생 중 화면 꺼짐 방지, 끊기면 자동 재접속

## 실행

```bash
npm install
```

개발 (서버 3001 + Vite 5173):

```bash
npm run dev
```

프로덕션처럼 한 포트로 실행:

```bash
npm run preview
```

## 배포

Node 서버 하나가 WebSocket과 빌드된 프론트를 같이 서빙하므로 배포는 한 번이면
됩니다. Render / Railway / Fly.io 어디든 됩니다.

| 항목 | 값 |
| --- | --- |
| Build Command | `npm install && npm run build` |
| Start Command | `npm start` |
| Port | `PORT` 환경변수를 자동으로 씁니다 |

> Vercel·Netlify 같은 서버리스 호스팅은 WebSocket을 계속 붙들고 있을 수 없어
> 이 앱에는 맞지 않습니다.

### 연습실에서 인터넷 없이 쓰기

노트북에서 `npm run preview`를 띄우고, 같은 와이파이의 휴대폰에서
`http://<노트북 IP>:3001` 로 접속하면 됩니다. 다만 HTTPS가 아니라서
화면 꺼짐 방지와 링크 복사는 동작하지 않습니다.
